# 心有灵犀 · 默契大挑战

> 双人默契小游戏：一人出题，一人作答，当场揭晓「你们有多默契」。
> 零后端 · 零依赖 · 分享即传播。

## 一句话定位

情侣 / 闺蜜 / 好友之间的社交货币型小游戏——「你敢来测测我们的默契吗？」
出题人从题库挑 5 道题并写下自己的答案，发给对方；对方作答后立刻生成本次"默契战报"（分数 + 单题对照 + 毒舌点评）。

## 为什么会有人用

- **社交裂变内建于玩法**：必须发给"那一个人"才能玩，微信场景天然适配；答完回传战报，完成一次双向互动。
- **轻**：5 道选择题 30 秒答完，无注册、无登录、无后端。
- **内容有趣**：恋爱/友情/脑洞三大题库 + 自定义出题，点评文案带梗，战报适合截图转发。

## 玩法流程

```
出题人 A                                挑战人 B
────────                               ────────
选题(≤5, 题库或自定义) ─┐
写下自己的答案         │
生成挑战(编码进链接/卡片) ────分享────────▶ 解码 → 依次答题(5题)
                                        ▼
        ◀────回传战报(再次分享)──── 立即出结果: 默契度战报
打开战报 → 逐题对照 B 的答案              (B 本地就能看到结果)
```

- 挑战载荷（题目 + 出题人答案）全部**编码进分享链接/卡片路径**，不依赖服务器。
- 战报回传同理：B 的结果页再分享回 A，A 打开即看逐题对照。
- 两人答案在载荷里做轻混淆（XOR + Base64URL），防"偷看答案"，但明眼人解不开。

## 技术方案（最小工作量取舍）

| 项 | 方案 | 理由 |
|---|---|---|
| 小程序端 | **原生 WXML/WXSS/JS**，无 npm、无云开发 | 微信开发者工具直接导入 `mp/` 即可运行，发布链路最短 |
| H5 端 | 同一套玩法的 **vanilla JS 孪生版**（`h5/`） | 部署到 GitHub Pages **现在立刻可玩**（含微信内置浏览器）；小程序过审前是全量兜底 |
| 共享逻辑 | `shared/core.js`（题库/编码解码/算分），UMD 双环境复用；`mp/utils/core.js` 为同步副本 | 一份内容两处使用 |
| 数据 | 全部本地：载荷走 URL，历史战报走本地存储 | 无后端 = 无服务器成本、无运维、无备案 |
| 部署 | `deploy.sh` 一键推送到 `YUFEI96HE/moque` 公共仓库，Pages 分支 `gh-pages` 自动上线 | 用户零手工操作 |

## 目录结构

```
moque/
├── README.md            ← 本文档
├── shared/core.js       ← 题库 + 编解码 + 算分（唯一事实源）
├── mp/                  ← 微信小程序（开发者工具导入此目录）
│   ├── project.config.json / app.* / sitemap.json
│   ├── utils/core.js    ← shared/core.js 的同步副本
│   └── pages/{home,create,battle}/   ← 首页 / 出题 / 答题+战报
├── h5/                  ← H5 孪生版（GitHub Pages 站点，自包含）
│   ├── index.html / style.css / app.js
│   └── core.js          ← 构建时从 shared/ 拷入
└── deploy.sh            ← 一键部署（main=完整项目，gh-pages=纯站点）
```

## 发布路径

**H5（已完成，零操作）**：https://yufei96he.github.io/moque/ （GitHub Pages，由 `deploy.sh` 自动维护）。国内直连 github.io 偶有抖动，正式运营可换自有域名或国内静态托管，页面本身无需改动。

**小程序（需用户一次性操作，约 10 分钟）**：
1. 打开微信开发者工具 → 导入 `mp/` 目录 → 游客模式即可在模拟器完整体验；
2. 注册个人小程序（免费）拿 AppID，填入 `project.config.json` 的 `appid`；
3. 上传 → 在 mp.weixin.qq.com 提交审核 → 发布。
